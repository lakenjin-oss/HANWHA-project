# 한화 테크 빌리지

한화시스템·한화에어로스페이스·한화오션의 기술을 작은 3D 마을에서 탐험하는 한국어 웹 게임입니다. 방향키로 입체 캐릭터를 움직이고 집 문으로 걸어 들어가면 실제로 이동 가능한 3D 실내가 나타납니다. 전시물을 살펴보며 기술 설명·미션·공식 출처를 확인할 수 있습니다.

따뜻한 색감과 둥근 형태의 아기자기한 마을을 독자적으로 제작했습니다. 캐릭터·지형·건물·실내 전시물은 Three.js의 입체 도형으로 직접 구성하며 외부 게임의 모델·텍스처·음악을 사용하지 않습니다.

## 실행

Node.js 20.19+ 또는 22.12+에서 프로젝트 폴더를 열고 실행합니다.

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. Windows에서 npm shim 실행에 문제가 있는 경우:

```powershell
& 'C:\Program Files\nodejs\node.exe' 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' install
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

## 탐험 방법

- **방향키 / WASD:** 캐릭터 이동. 건물·나무·가구·바다와 충돌합니다.
- **집 문으로 걸어가기:** 문 영역에서 화면이 전환되며 3D 실내로 입장합니다.
- **실내 전시물 앞에서 E:** 기술 설명, 순서 미션, 질문 안내소와 출처를 엽니다.
- **실내 출구로 걸어가기:** 집 밖의 현관 앞으로 돌아옵니다. '집 밖으로' 버튼도 있습니다.
- **안내서의 집 선택:** 문까지 자동으로 걸어간 뒤 입장합니다. 설명 창이 즉시 열리지 않습니다.
- **Esc:** 설명·설정 창을 닫고 탐험을 이어갑니다.
- **마을 안내 접기 / 넓게 탐험하기:** 화면 오른쪽 위 버튼으로 더 넓게 둘러볼 수 있습니다.

중앙 광장에서 세 회사의 집으로 걸어가면 각각의 마을로 이동합니다. 상단 회사 버튼으로도 이동할 수 있습니다. 회사마다 3개씩, 총 9개의 기술 실내가 있으며 각 실내에 고유한 전시물을 배치했습니다. 실내에서도 방향키로 자유롭게 이동합니다.

'직접 체험'에서 올바른 순서로 단계를 선택하면 기술 배지를 얻습니다. 도감에서 방문한 집의 설명을 다시 읽고, 방문하지 않은 집으로 걸어갈 수 있습니다. 이름·옷 색상·도감·배지는 브라우저에만 저장되며 질문 내용은 영구 저장하지 않습니다.

## AI 주민 대화

다섯 집 주민 앞에서 E키를 눌러 질문할 수 있습니다. Gemini 연결과 키 설정은 [실행 안내](docs/gemini.md)를 따르세요. 키가 없으면 도감 모드이며, 실제 AI 연결은 Python 서버에서 설정합니다.

## 질문 모드

기본 버전은 API 키 없이 작동하는 **공식 자료 기반 도감 모드**입니다. 21개 출처를 정리한 설명과 비교 결과를 제공합니다. 실시간 생성형 AI가 연결된 경우에는 화면에 AI 모드로 구분합니다.

실제 생성형 AI를 연결하려면 `docs/backend.md`에 따라 Python FastAPI 서버를 실행하고 프런트엔드 `.env`에 `VITE_API_BASE_URL=http://127.0.0.1:8000`을 설정합니다. API 키와 모델은 서버 환경변수에서만 관리합니다. Python 서버는 정적 사이트에 포함되어 실행되지 않으므로 별도 호스팅이 필요합니다. 외부 서버 연결 시 HTTPS와 명시적인 CORS·접근 통제를 설정합니다.

## 구현

- React: 마을 안내, 대화창, 도감, 비교와 설정 UI
- Three.js: 실제 3D 캐릭터·지형·건물·실내, 조명·그림자·카메라
- 자체 AABB 충돌·경로 탐색: 이동 제한, 안전한 출현 위치, 자동 이동
- FastAPI: 선택적 임베딩 검색과 출처 기반 AI 답변

이 버전은 절차적으로 구성한 입체 모델과 자체 충돌 처리를 사용합니다. GLB 파일이나 Rapier 물리 엔진을 사용한 버전이 아닙니다. 기술 미션은 개념 이해를 위한 교육용 체험입니다.

## 확인과 자료 수정

```powershell
npm test
npm run build
```

공식 자료를 수정했다면 서버 JSON도 갱신합니다.

```powershell
node export-content.mjs
```

- `src/game/VillageGame.js`: Three.js 실행, 캐릭터·카메라·입장·퇴장
- `src/game/world3d.js`: 중앙 마을·회사 마을·기술 실내 모델
- `src/game/navigation3d.js`: 충돌·안전 위치·경로 탐색
- `src/data/content.js`: 기술 9개, 출처 21개, 회사 비교·미션
- `src/lib/learning.js`: 도감 답변·기록·API 연결
- `backend/`: 선택적 FastAPI·검색·출처 검증·사용량 제한
- `docs/sources.md`: 공식 자료 목록
- `docs/evaluation.md`: 평가 질문 30개와 사용자 평가 양식
- `docs/demo.md`: 5분 발표 시나리오

PC 웹과 키보드 조작을 우선으로 제작했습니다. 모바일에는 보조 방향 버튼을 제공합니다. 실행에는 WebGL을 지원하는 브라우저가 필요합니다. 회사 공식 서비스가 아닌 학습 프로젝트이며 자료 확인일은 2026-10-14입니다.
