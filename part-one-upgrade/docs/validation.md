# 구현 검증 기록

검증일: 2026-10-15 (Asia/Seoul). 아래는 구현 중 실제로 수행한 자동 테스트와 브라우저 확인 기록입니다. 취업준비생 사용자 조사나 실제 LLM 정확도 평가 결과가 아닙니다.

## 자동 검증

| 항목 | 결과 | 실행 범위 |
|---|---|---|
| 프런트엔드 단위 테스트 | 38개 통과 | 회사·시설 콘텐츠, 도감 진행 상태, 체험 순서, 자료 부족·데모 답변 |
| Python 백엔드 테스트 | 38개 통과 | 핵심 로직 25개 + API 계약·실제 자료 HTTP 검증 13개 |
| Python 구문 검사 | 통과 | `python -m compileall -q backend` |
| 실제 자료 HTTP 검증 | 통과 | 시설 9개와 우주·해양·방산 비교 3개를 FastAPI TestClient로 호출 |

백엔드는 `python -m unittest discover -s tests -p 'backend*' -v`로 실행했습니다. API 키는 빈 값으로 고정했으며 공급자 응답 검증·실패·한도 테스트는 모의 응답을 사용했습니다. 외부 AI API 호출은 하지 않았습니다. 설치된 Starlette의 TestClient에서 httpx 관련 사용 중단 예고가 표시되었지만 모든 HTTP 계약 테스트가 완료됐습니다.

수록된 자료는 9개 시설의 문단 21개입니다. 시설별 2건 이상인지, 문단 ID가 고유한지, 공식 HTTPS 주소인지, 확인일이 있는지 검사했습니다. 이 개수는 서로 다른 원문 문서가 21개라는 뜻은 아닙니다.

질문·출처 검증은 다음을 포함합니다.

- 알 수 없는 “초전도체 설명해줘”를 현재 시설 설명으로 대체하지 않고 자료 부족으로 반환합니다.
- 정확한 탐지거리, 근거 없는 특정 선박 공동 건조, 잘못 연결한 회사·기술, 채용 일정, 허구 출처 생성 요청을 자료 부족으로 안내합니다.
- 존재하지 않는 출처 ID, 다른 회사 문단 인용, 근거 없는 수치·단위·협업 문구, 일부 회사만 있는 AI 비교 응답을 거부합니다.
- 비교 행은 해당 회사가 인용한 문단으로 검증하며, 다른 회사의 수치나 협업 문구를 근거로 섞지 않습니다.
- 동시 요청의 하루 한도와 서울 자정 초기화를 확인합니다. API 실패는 재시도 가능한 오류로 반환하며 키를 응답에 노출하지 않습니다.

## 실제 브라우저에서 확인한 범위

- 기본 화면 렌더링과 1440px 화면의 게임·안내 패널 배치를 확인했습니다.
- 캐릭터가 레이다 연구소까지 자동 이동하고 쉬운 설명 패널을 여는 흐름을 확인했습니다.
- 레이다의 3단계 체험을 완료해 배지 1개를 얻고, 새로고침 후에도 진행이 유지되는 것을 확인했습니다.

다른 시설과 모바일·충돌·전체 키보드 접근성의 추가 확인은 이 문서의 기록만으로 완료됐다고 보지 않습니다. 전체 페이지 스크린샷 도구는 제한 시간 초과로 완료되지 않았으며, 이를 성공한 검증으로 계산하지 않았습니다.

## 아직 실시하지 않은 평가

- 실제 공급자 키를 사용하는 LLM·임베딩 연결, 응답 시간 및 실제 호출 비용 측정.
- 30개 평가 질문의 원문 대조를 포함한 사람의 정확성·이해도 채점과 27개 이상 합격 여부.
- 취업준비생 3~5명 사용자 테스트와 80% 이상 이해 기준 충족 여부.
- 공개 배포 환경의 여러 사용자 부하·공용 예산 제한·운영 모니터링.

평가 질문 및 사용자 테스트 양식은 [평가 안내](evaluation.md)를 사용합니다. 인용 ID와 수치 검사만으로 모든 답변의 의미적 정확성이 자동 보장되지는 않으므로, 실제 AI 연결 후에는 별도 원문 대조가 필요합니다.
