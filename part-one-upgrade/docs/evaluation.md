# 평가 질문과 검증 안내

이 문서는 평가용 질문과 합격 기준이다. 실제 취업준비생 사용자 테스트 결과나 LLM 정확도 측정값을 의미하지 않는다. 실행한 테스트의 결과는 실행 안내서 또는 실행 로그에서 확인한다.

## AI·설명 평가 질문 30개

각 질문은 정확성 1점, 이해도 1점, 출처 연결 1점으로 평가한다. 사실 오류 또는 존재하지 않는 출처가 있으면 해당 질문은 실패다. 질문당 3점을 합격으로 보고 27개 이상 합격을 목표로 한다. 비유와 실제 기술의 차이도 확인한다.

## 자동 검증과 수동 검증

자동 검증: 회사와 시설 ID 연결, 시설당 공식 자료 2건 이상, source ID의 고유성, 응답의 source ID 존재 여부, 회사 필터·비교 균형, 자료 부족 반환, API 실패와 일일 제한 처리를 확인한다. 순서 퀴즈의 성공·실패 및 완료 상태도 검증한다.

수동 검증: 30개 답변의 의미와 원문 근거를 확인한다. 회사 선택, 9개 시설의 올바른 화면, 키보드와 클릭 이동, 건물·해안 충돌, 패널 중 이동 정지, 닫기 후 위치 유지, 도감 저장·초기화를 확인한다. 작은 화면에서 버튼을 누르고 문장을 읽을 수 있는지도 확인한다.

외부 LLM 연결 여부를 결과에 기록한다. API 키 없는 데모 설명 검증을 LLM의 정확도 검증으로 보고하지 않는다. 비용은 실제 토큰 사용량과 설정한 단가로 계산하며, 측정하지 않은 시간·비용을 결과에 적지 않는다.

## 취업준비생 사용자 테스트 양식
