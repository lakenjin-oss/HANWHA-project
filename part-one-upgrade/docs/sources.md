# 공식 자료 목록과 사용 범위

현재 콘텐츠는 `src/data/content.js`의 9개 시설과 출처 21건에 연결되어 있다. 시설마다 한화 회사·그룹의 자료가 2건 이상 있으며, 항공엔진의 일반 작동 원리를 위해 NASA 자료 1건을 추가했다. 아래 확인일은 카탈로그의 `checkedAt` 값이다. 뉴스의 발표일과 자료 확인일은 서로 다르다.

문서의 `body`는 학습용으로 요약한 문단이며 원문 전체나 직접 인용문이 아니다. 비유와 체험 순서는 이해를 돕는 설명이다. 성능 수치·계약·특정 제품의 공동 공급 관계를 요약에서 추론하지 않는다. 회사 비교는 각 사업의 역할을 비교하며, 한화오션의 우주 분야는 현재 자료가 부족하다고 표시한다.

## 검증과 갱신 방법

- 출처 ID는 고유하며, 답변의 출처는 카탈로그의 ID로만 연결한다. HTTPS와 공식 도메인 경계를 검사해 비슷한 외부 도메인을 허용하지 않는다.
- 출처 변경 시 원문 내용을 확인하고 `body`, 시설 설명, `checkedAt`을 함께 갱신한다. URL 이동이나 접근 실패는 공식 회사·그룹 페이지에서 대체 자료를 찾고 기록한다.
- `npm test`는 출처 21건의 메타데이터와 연결 무결성, 회사별 비교 균형, 30개 데모 평가 질문을 검사한다. 실시간 URL 가용성이나 외부 LLM의 정확도까지 증명하는 테스트는 아니다.
- 실제 사용자 이해도 평가는 `docs/evaluation.md`의 미실시 양식으로 별도 진행한다. 자동 테스트 결과를 사용자 테스트 결과로 보고하지 않는다.
