# 5분 발표 시나리오 — 실제 3D 마을 탐험

시연 전 서버를 실행하고 탐험 기록을 초기화합니다. API를 연결하지 않았다면 공식 자료 기반 도감 모드임을 밝힙니다. 캐릭터·집·마을은 직접 구성한 입체 모델이며, 특정 게임의 그래픽을 복제하지 않은 독자적인 디자인입니다.

## 이동과 입장 확인

방향키로 캐릭터를 움직입니다. 중앙 광장의 회사 집 문으로 걸어가 마을을 바꾸고, 기술의 집 문으로 걸어가 실내로 들어갑니다. 실내에서도 캐릭터를 움직여 전시물 앞에서 E를 눌러야 설명이 열립니다. 입장만으로 설명 창이 자동으로 열리지 않습니다.

| 시간 | 화면과 행동 | 발표 문장 |
|---|---|---|
| 0:00–0:40 | 중앙 광장에서 방향키로 걷기, 가구와 집 둘러보기 | “기술 용어를 외우는 대신 작은 3D 마을을 직접 돌아다니며 기술의 역할과 가치를 발견합니다. 지형·캐릭터·집은 모두 입체 모델입니다.” |
| 0:40–1:15 | 한화시스템 집 문으로 이동해 회사 마을 입장 | “회사마다 방문할 집과 체험이 다릅니다. 집 문으로 걸어가면 새로운 마을로 이동합니다.” |
| 1:15–2:05 | 레이다 연구소 문으로 입장, 실내에서 걷고 전시물 앞에서 E | “건물 설명을 띄우는 데서 끝나지 않고 실제 집 안을 돌아다닐 수 있습니다. 전시물을 살펴보면 레이다의 역할을 쉬운 설명과 비유로 배웁니다.” |
| 2:05–2:45 | 레이다 단계 미션 완료, 출처 확인, 설명 닫고 출구로 걸어가기 | “보내고, 받고, 해석하는 순서입니다. 개념을 이해하면 배지가 도감에 기록됩니다. 설명의 공식 출처를 확인한 뒤 밖으로 나갑니다.” |
| 2:45–3:30 | 한화에어로스페이스 마을, 발사센터 방문 | “발사체는 우주로 보내는 역할을, 위성 탑재체는 관측 정보를 얻는 역할을 합니다. 각 집의 전시물도 해당 회사 기술에 맞게 달라집니다.” |
| 3:30–4:10 | 한화오션 마을, LNG 집 입장 | “LNG 운반선은 에너지를 필요한 곳까지 옮깁니다. 집 안의 선박 모형과 체험으로 운송의 가치를 이해합니다.” |
| 4:10–4:40 | 회사 비교에서 해양 역할 비교, 도감 열기 | “회사의 사업 역할을 비교합니다. 특정 공동개발이나 공급 관계는 근거 없이 단정하지 않습니다. 방문한 집과 배지는 다시 볼 수 있습니다.” |
| 4:40–5:00 | 질문: ‘레이다의 정확한 탐지거리는 몇 km야?’ | “자료에 없는 수치를 추측하지 않습니다. 출처가 있으면 설명하고, 부족한 근거는 부족하다고 안내합니다.” |

회사 이동 시간은 상단 회사 버튼으로 줄일 수 있습니다. 집을 찾기 어려우면 안내서에서 집을 선택해 문까지 자동 이동합니다. 가이드 패널을 접으면 마을을 더 넓게 볼 수 있습니다.

## 질문에 대비하기

- 게임은 교육용 개념 체험입니다. 실제 장비 성능이나 작전 절차를 계산하지 않습니다.
- Three.js의 입체 도형과 자체 충돌·경로 탐색을 사용합니다. 외부 게임 모델이나 음악을 사용하지 않습니다.
- 도감 모드는 정리된 자료를 제공하며, 생성형 AI는 별도 Python 서버와 API 설정 후 연결합니다.
- 도감·배지·이름은 브라우저에 저장됩니다. 사용자 질문은 영구 저장하지 않습니다.
- 실제 사용자 이해도와 생성형 AI의 정확도는 별도 평가가 필요합니다. 준비된 평가표를 측정 결과로 제시하지 않습니다.
